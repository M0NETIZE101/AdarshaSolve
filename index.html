How it works

Three steps from pocket to microphone.

  1. 1

    Open the receiver on your PC

    It registers a PeerJS ID with the signalling cloud and waits for a call.

  2. 2

    Start the mic on your phone

    The browser captures audio and calls the PC using the peer ID you entered.

  3. 3

    Audio flows peer-to-peer

    WebRTC negotiates the connection; the receiver plays the stream instantly.

Demo pairing ID: this build uses a fixed PC ID (my-pc-receiver). If two people use it at once, click Reconnect on the receiver.

Good to know

Why HTTPS?
Browsers only grant microphone access on secure origins. Cloudflare Pages provides HTTPS by default.
Can I use it as a system mic?
This demo plays audio in the browser. Route it into apps like Zoom or OBS using a virtual audio device (VB-CABLE on Windows, BlackHole on macOS, PipeWire on Linux).
Does audio pass through a server?
No. PeerJS is only used for signalling — the media travels directly between your phone and PC.
Does it work across networks?
Usually, via STUN. Symmetric NATs may need a TURN server for reliable connections.
